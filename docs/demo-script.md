# Demo Script for Judges

## 60-90 Second Version

Hello judges, this is Rice Doctor AI, a rapid agricultural assistant for ASEAN farming workflows powered by Qwen on Alibaba Cloud DashScope.

The problem we focus on is simple: smallholder farmers and field teams often only have a phone image, limited expert access, and urgent decisions to make.

Our workflow starts with a crop photo. We send that image to Qwen-VL for disease analysis, then turn the result into three practical outputs:
- farmer-friendly treatment recommendations
- monitoring-ready reports for agricultural teams
- multilingual guidance that can be used in the field

What makes this strong technically is that the architecture is model-agnostic. The business workflow is separated from the provider layer, so we can route image and text tasks through Qwen while keeping the rest of the product stable.

For judges, the key point is that this is not just a model demo. It is a full workflow demo:
1. image in
2. disease insight out
3. recommendation generated
4. report drafted
5. farmer guidance localized

This means Qwen is not only analyzing images here. It is powering an end-to-end agricultural decision-support loop.
